# W02 LP 정책 검증 대장 (2026-10-16)

상태: 익명 규약·예시를 사용자가 텍스트로 제공하기로 선택, 아직 미수신. 금융 계산 변경 없음. [GP 정책 검증 대장](https://github.com/choby-pm/vc-erp-gp/blob/main/docs/100_policy-validation.md)은 이번 로컬 작업 산출물로 아직 원격 반영 전이다.

| 정책 | 현재 가정·근거 | 상태·확인 상대 | 영향 코드 | 필요한 질문·후속 결정 |
|---|---|---|---|---|
| 기준수익·반환 | GP 납입 전액 단리, 중간 반환 차감 없음(D15). LP는 GP 분배 사본과 자체 수령 원장 분리 | 미확인 / 사용자 경유 규약 담당 | GP `distributions.ts`, LP `lib/services/distributions.ts` | 반환일 이후 기초·일수 규칙·적용 조합, 확정 분배 보존·정정 수신 방식 |
| 관리보수 | GP 투자 중 약정액·이후 잔액·365일 일할(D16), LP는 보고 요약 수신 | 미확인 / 규약·운영 담당 | GP `management-fees.ts`, LP `reports.ts` | 전환일·제외 자산·청산 보수, 이전 청구 보존·적용일 |
| 성과보수·세금 | 캐치업·클로백 없음, GP 성과보수 이익분배, LP 수령액 세금 차감 없음(L39) | 미확인 / 규약·회계 담당 | GP `distributions.ts`, LP `distributions.ts`, `performance.ts` | 세전 분배와 실제 세후 수령 차이·원천징수·환수, 과거 원장 재계산 여부 |
| 투자 의무 | 기존 보고 주목적 비율·약정액 분모·기간 중 참고(L34) | 미확인 / 운용·규약 담당 | `compliance.ts`, GP `investments.ts`, `reports.ts` | 기간·조건·인정액 예시; W03 선택한 제품 정책은 아래 기록, 현업 검증 아님 |
| 회계·보고 | GP 원가법·달력연도(D35), LP 최근 보고 NAV 롤포워드(L40), 자체 연동 | 미확인 / 회계·보고 담당 | `reports.ts`, `performance.ts`, GP `accounting.ts` | 회계 기준·평가 손익·주기·제출처, 발행 보고·청산 최종값 보존 |
| 취소·반환 | 선정·콜 취소 일부 전파 미지원, 분배 반환은 외부. 우리/GP 기록 독립 | 미확인 / 자금·기관 업무 담당 | `commitments.ts`, `capital-calls.ts`, `distributions.ts`, `gp/inbox.ts` | 취소 결정일·실제 반환일·정정 통보 시점, 실제 송금건 삭제 금지 |

자료 형식: `익명 조합 유형·기간 / 조항 요약 / 날짜·금액 입력 / 기대 결과 / 출처 성격`. 이름·회사명·민감 원문은 필요 없다. 예시만 확보한 항목은 그 범위에서만 검증하고 확인 상대·적용 범위·검증일을 기록한다.

가상 검토 예시: 10억 납입 후 중간에 4억 반환, 연 8% 단리일 때 전액 유지/차감 산식의 결과를 비교한다. 약정 100억·의무 하한 20%에 인정액 8억이면 투자 비율 8%, 달성률 40%; 상한 6억에 인정 5억이면 한도 사용 5억·잔여 1억. 이는 실제 규약 근거가 아니다.

사용자 확정 W03 정책(2026-10-16): 금액·약정액 비율 하한/상한, 담당자 인정, 집행 원금·명시적 과거 거래 재판정, 과거 보고 보존. 조합원 LP에게 기업명 포함 공개용 근거만 읽기 전용 제공. 담당자 개인정보·투심 메모 제외. GP 판정을 LP가 수정하거나 LP 자체 원장을 GP 값으로 덮어쓰지 않는다.

금융 계산을 변경하기 전에 정책 버전·적용일·과거 확정 분배/보고/결산 보존·기존 데이터 재계산 범위·정정 연동을 별도 결정한다. AI는 현재 가정과 질문 정리·코드 근거 확인을 수행했다. 실무 확인을 대신하지 않았다.
