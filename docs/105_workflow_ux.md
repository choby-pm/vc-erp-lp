# W07 업무 문구·결재 확인 정보 (2026-10-17)

일반 사용자 설명의 R/L/BR 번호를 업무 문구로 정리하고 개발 문서·주석의 추적 번호는 유지했다. 모든 공통 금액 입력은 원 단위를 표시하며 기존 원 단위 저장·파싱은 유지한다. 새 공고 부문의 분야는 자동으로 ‘초기’를 선택하지 않고 사용자가 명시적으로 선택한다. 로그인 중지 계정은 이력 보존 상태임을 표시한다.

선정·납입·투표 결재 확인창은 현재 기관·GP·조합·금액/회차/총회·승인 결과를 표시한다. 납입 승인은 실제 송금이 아니라 송금 대기이며 송금 전 취소와 송금 후 취소 행을 통한 정정을 구분한다. 투표는 제출 시점 상태 재검사와 전송 장애 재시도를 설명한다. 기존 역할·자기 승인 금지·서버 결재 규칙은 유지했다.

양쪽 lint·타입·프로덕션 빌드 통과. GP 분배 기준은 실제 Chrome에서 확인했다. 현재 LP 데모에 대기 결재가 없어 새 확인창의 실제 승인 클릭은 W07에서 미실행이다. 코드·타입 검증과 실제 화면 검증을 구분한다. 단순 문구를 복제하는 테스트는 추가하지 않았다.

데모 재로그인 후 맥락 복원은 검토만 했다. 기관 변경 시 이전 기관 주소를 자동 복구하는 기능과 실제 사용자 권한 전환 기능은 추가하지 않았다. 역할별 시연은 같은 기관을 명시적으로 선택해 진행한다. 실무 규약 확인은 W02 자료 수신 후 별도로 한다.
