# VC ERP (LP) — 기획 문서 모음

출자기관(LP)이 여러 GP의 여러 조합에 한 출자를 계획·심사·약정·납입·사후관리·회수·성과 분석까지 다루는 ERP MVP.
같은 저장소 옆의 GP 시스템(`vc-erp/gp`)과 연동 API·웹훅으로 연결된다.
똑똑 PM 지원용 개인 작업물이며, 실제 서비스와 무관한 연구 목적 프로젝트다.

## 기술 스택 (GP와 같음)

- 프론트엔드·서버: Next.js
- 스타일: Tailwind CSS
- DB: PostgreSQL (Neon, GP와 별도 DB), SQL 직접 작성
- 배포: Vercel (GP와 별도 프로젝트)
