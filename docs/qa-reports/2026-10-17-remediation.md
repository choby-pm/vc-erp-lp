- `npm run lint`: 통과.
- `npx --no-install tsc --noEmit`: 통과.
- `npm run build`: 통과 (Next.js 타입 검사 포함).

- 일반 화면의 R/L/BR 코드·‘은퇴’ 문자열 검색: 주석·규칙 식별자 용도를 제외한 잔존 없음.
- 실제 브라우저 재실행·배포는 하지 않았다. 문구 변경을 복제하는 테스트는 추가하지 않았다.
